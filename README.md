# 🏫 Mapa da Escola Acessível

Este projeto apresenta um mapa escolar simplificado, projetado para orientar alunos, visitantes e comunidade escolar na localização rápida de seus ambientes através de uma interface clara, previsível e inclusiva.

---

### ♿ Boas Práticas de Acessibilidade Aplicadas

1. **Símbolos Acompanhados de Texto:** As áreas do mapa e cards utilizam ícones/emojis acompanhados obrigatoriamente do nome por extenso (ex.: `🏫 Entrada`), garantindo compreensão para pessoas daltônicas ou com dificuldades de leitura de símbolos.
2. **Combinação Dupla (Não depende apenas de cores):** Além de cores diferenciadas por zona (ensino, recreação, área técnica), cada local conta com títulos visíveis e bordas marcadas.
3. **Menu de Navegação Interna:** Links que permitem pular diretamente para a visualização do mapa ou para as descrições dos ambientes (`<nav>`).
4. **Contraste de Cores Registrado (WCAG):** Textos e títulos possuem alto contraste em relação aos planos de fundo clara e bordas laterais.
5. **Tipografia Legível:** Uso da fonte sem serifa (`Arial, Helvetica`) com boa altura de linha (`line-height: 1.6`) para facilitar a leitura.
6. **Responsividade para Dispositivos Móveis:** O layout se reestrutura em coluna única em telas de smartphones através da regra `@media (max-width: 650px)`.

---

### 🚀 Publicação no GitHub Pages

1. Crie um repositório público no [GitHub](https://github.com/) com o nome `mapa-da-escola`.
2. Adicione os arquivos `index.html`, `style.css` e `README.md`.
3. Vá em **Settings** > **Pages**.
4. Em **Branch**, selecione `main` e a pasta `/ (root)`.
5. Clique em **Save** e aguarde o link público ser gerado.
